Project Title: Blockchain-Based Voting System
Team Size: 3
Course: Fundamentals of Software Project Management (FSPM)

Description:
Planned and documented a Blockchain-Based Voting System as part of the Fundamentals of Software Project Management course. The project aimed to enhance election transparency and security through blockchain technology. Created a detailed budget and resource allocation plan using Microsoft Excel. Used Microsoft Project to develop a comprehensive project timeline, including WBS, Gantt charts, risk management, and cost analysis. The focus was on project planning, team coordination, and applying software project management principles to a real-world tech solution.
